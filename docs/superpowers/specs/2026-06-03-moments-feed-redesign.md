> 状态: 定稿 | 日期: 2026-06-03

## 1. 总体设计定位

### 1.1 视觉风格
**年轻潮流风（暖系撞色）** — 不走玻璃拟态/双色/水晶特效，采用干净现代的设计语言。

### 1.1.1 设计铁则（不可违反）
1. **禁止使用 Emoji 作为功能图标** — 所有图标统一使用 `lucide-react` 图标库，保持视觉专业性和一致性
2. **禁止卡片边框** — 不使用 `border` 属性区分卡片，以阴影（`box-shadow`）和背景色差异替代，保持界面轻盈透气
3. **实现阶段使用前端 Skill** — 编码实现时调用 `frontend-design` / `ui-ux-pro-max` / `web-design-engineer` 等前端技能确保设计质量

## 2. Feed 首页布局

### 2.1 页面结构（从上至下）

```
┌──────────────────────────────────────┐
│ 动态   推荐 | 关注        Search Bell │  ← 顶部导航（lucide 图标）
├──────────────────────────────────────┤
│  热门话题轮播 Banner                  │  ← 渐变背景 + 话题名 + 参与数
│  # 咖啡馆探店  [活跃用户头像×3]       │     内嵌该话题活跃用户
│  [<] [ TOP 1/4 · · · · ] [>]        │     轮播指示器 + 左右切
├──────────────────────────────────────┤
│ [我的] | #探店 [用户] #电影...        │  ← 磁贴混合池
│  固定  | <── 自动滚动轮播 ───>       │     发布位固定 + 其余轮播
├──────────────────────────────────────┤
│  Feed 卡片（无边框，仅阴影）           │
│  [头像] 用户名 LV.12  · 时间·地点     │
│  正文内容...                          │
│  [图片 60%宽 圆角 不铺满]             │
│  # 标签  # 标签                       │
│  Heart(238)  MessageCircle(56) Share2 │
├──────────────────────────────────────┤
│  Feed 卡片                            │
│  ...                                 │
├──────────────────────────────────────┤
│                          [⊕] ← 悬浮   │  ← 右下角悬浮发布
└──────────────────────────────────────┘
```

### 2.2 顶部导航

- 左侧：「动态」页面标题（15px / 800 字重）
- 中间：**「推荐」|「关注」** 双 Tab，选中态：珊瑚橙 `#FF6B6B` 下划线（2.5px），未选中：`#BBA0A0`
- 右侧：`Search` + `Bell` lucide 图标（20px，颜色 `#BBA0A0`）
- 推荐 Tab 显示全部内容（话题推荐 + 用户推荐 + Feed 流）
- 关注 Tab 仅显示已关注用户的动态

### 2.3 热门话题轮播 Banner

- 全宽渐变背景（珊瑚橙 → 暖黄），圆角 14px，高度约 96px，无边框
- 显示内容：`Hash` 图标 + 话题名称、简介、参与人数
- 底部嵌入该话题的**活跃用户头像**（3 个重叠小头像 + "等 N 人活跃" 文字）
- 轮播：4 个 TOP 热门话题自动切换，`ChevronLeft` / `ChevronRight` 箭头 + 圆点指示器
- 点击 Banner → 跳转该话题聚合页

### 2.4 磁贴混合池（话题 + 用户 + 发布入口）

**布局：** 单行横滑，发布入口固定在左侧，其余自动向左慢速轮播

**发布入口（固定位）：**
- 用户自己的头像（32px） + 右下角叠加 `Plus` 小圆
- 文字：「我的」+「发布」
- 通过阴影微增强 + 圆角 14px 与滚动区区分，**不使用边框**
- 点击 → 打开发布动态弹窗

**话题磁贴（可滚动）：**
- 正方形卡片（约 82px），浅色渐变底 + 圆角 14px，无边框，仅用 `box-shadow` 微阴影
- `Hash` 图标 + #话题名 + 讨论数
- 底部 2-3 个用户小头像重叠

**用户磁贴（可滚动）：**
- 正方形卡片（约 60px），白色底 + 圆角 14px，无边框，微阴影
- 用户头像 + 昵称 +「关注」按钮
- 推荐非好友的高活跃用户

**交互：**
- 自动向左慢速轮播，循环无缝
- 手指触摸可手动滑动
- 点击话题磁贴 → 跳转话题聚合页
- 点击用户磁贴 → 跳转用户主页

### 2.5 Feed 动态卡片

**卡片结构（无边框，仅阴影区分）：**
1. **头部** — 用户头像(28px) + 昵称 + LV 等级标签(珊瑚橙小 pill) + 时间 + 地点 + 右上角 `MoreHorizontal`
2. **正文** — 用户文案，颜色 `#3D2B2B`，字号 12-13px，行高 1.6
3. **配图区域** — 图片不铺满卡片、留有内边距：
   - 1 张图：60-75% 卡片宽度，左对齐，圆角 10px
   - 2 张图：左右等分
   - 3-9 张图：均等网格，间距 3-4px
4. **话题标签** — `# 标签名` pill，暖色底 `#FFF0E5` + 珊瑚橙文字（或紫色方案），可点击跳转话题页
5. **互动栏** — `Heart` 点赞数 / `MessageCircle` 评论数 / `Share2` 分享数；已点赞时爱心变珊瑚橙

**交互：**
- 点击头像/昵称 → 用户主页
- 点击图片 → 全屏预览（左右滑动多图）
- 点击 `# 标签` → 话题聚合页
- 点击 `Heart` → 点赞动画（心形粒子爆散）+ 数字 +1
- 点击 `MessageCircle` → 打开动态详情页/评论区
- 点击 `MoreHorizontal` → 更多操作（举报/不感兴趣）
- 上滑加载更多，下拉刷新

### 2.6 右下角悬浮发布按钮

- 圆形（48px），纯渐变底（珊瑚橙 → 暖黄），不含用户头像
- 中间白色 `Plus` 图标（22px，颜色 `#FF6B6B`）
- 投影：`0 4px 20px rgba(255, 107, 107, 0.3)`，**不使用边框**
- 固定定位，不随滚动移动
- 点击 → 打开发布动态弹窗

## 3. 话题系统设计

### 3.1 三层话题入口

| 层级 | 位置 | 功能 |
|---|---|---|
| **A · 行内标签** | Feed 卡片内部 `# 标签` | 点击跳转话题聚合页 |
| **B · 热门轮播** | Feed 顶部 Banner | 4 个 TOP 话题轮播展示 |
| **C · 聚合卡片** | 混入 Feed 流（偶尔出现） | 话题信息 + 3 条内容预览 + 参与按钮 |

### 3.2 话题自创 + 自动沉淀机制

**创建：** 用户发布动态时输入 `#任意文字`，自动创建或匹配已有话题，无需额外操作。

**热度等级（由使用量决定）：**

| 等级 | 条件 | 展示位置 |
|---|---|---|
| 新建 | 使用 < 10 次 | 仅在卡片内标签可见 |
| 活跃 | 使用 10-99 次 | 话题页可搜索到 |
| 热门 | 使用 ≥ 100 次 | 轮播 Banner + 聚合卡片 + 话题页推荐 |

**自动升降级：**
- 达标后自动升级，无人工审核
- 7 天内使用量低于当前等级阈值 → 自动降级
- 保证榜单新鲜度

**轮播排序：** TOP 4 按参与人数 + 近期增量综合排序。

## 5. 发布动态页面（全屏独立路由）

**路由：** `/moments/publish`

### 5.1 页面布局

```
┌─────────────────────────────────────┐
│  取消        发布动态          发布   │  顶栏
├─────────────────────────────────────┤
│  [大文本输入框]                      │
│  此刻想记录什么...                    │
│                           (环·76)    │  环形字数指示器
│                           /500      │
├─────────────────────────────────────┤
│  [图1] [图2] [图3] [+ 添加图片]      │  3列图片网格
├─────────────────────────────────────┤
│  [录制按钮] 语音动态 [波形] 0:32      │  语音录制区（可选）
├─────────────────────────────────────┤
│  MapPin  所在位置     上海·徐汇  >   │  选项区（无边框，底色微区分）
│  Eye     谁可以看      公开      >   │
│  Bell    提醒谁看      未选择    >   │
├─────────────────────────────────────┤
│  #话题   @好友   图片   语音   位置   │  底部工具栏（5键圆形）
└─────────────────────────────────────┘
```

### 5.2 顶栏
- 左侧「取消」（14px / `#BBA0A0`） → 返回上一页
- 中间标题「发布动态」（15px / 800）
- 右侧「发布」胶囊按钮：空内容时灰色 `#DDD`，有内容时渐变珊瑚橙 `#FF6B6B → #FFB347`

### 5.3 文本输入区
- 大输入框，占位文案「此刻想记录什么...」，min-height 120px
- 右下角环形字数指示器：conic-gradient 进度环，内圈白色底，显示当前字数
- 颜色规则：0-450 珊瑚橙环 / 451-500 红色环 + 数字变红
- 字号 14px，行高 1.8，颜色 `#3D2B2B`

### 5.4 图片区
- 3 列网格，gap 6px，每格 aspect-ratio 1:1
- 已选图片：右上角 × 删除按钮（半透明黑底 + 白 ×）
- 添加按钮：暖色底 `#FFF0E5` + `Plus` 图标 + "添加图片" 文字
- 最多 9 张，达到上限后隐藏添加按钮

### 5.5 语音录制区
- 整行卡片：录制按钮 + 状态文字 + 波形 + 时长 + 删除
- **待录音状态**：红色圆按钮 + "最长 60 秒"
- **录制中状态**：红色方形停止按钮 + 外圈脉冲波纹 + 实时波形动画 + 计时
- **已录制状态**：播放波形 + 时长 + "点击可重录或删除"
- 点击 × 删除语音，可重新录制
- 语音动态在 Feed 卡片中以**渐变播放条**展示：播放按钮 + 波形图 + 进度时间

### 5.6 选项区
- 三行选项，白色底无边框，底色微区分
- 每行：lucide 图标（MapPin / Eye / Bell）+ 标签 + 当前值 + 右箭头
- 点击跳转二级选择页

### 5.7 底部工具栏
- 固定底栏，5 个圆形按钮均分，图标 + 文字标签
- `#` 话题 — `#FFF0E5` 底色 + `#FF6B6B`
- `@` 好友 — `#F3EFFF` 底色 + `#A18CD1`
- 图片 — `#F0FFF4` 底色 + `#4ECDC4`
- 语音 — 渐变珊瑚橙底，突出为最核心的创意功能
- 位置 — `#FFF8F0` 底色 + `#FFB347`

- 返回箭头 + 作者头像(32px) + 昵称 + LV 标签 + 时间地点 + 关注按钮(渐变胶囊)

  - 1 张：居中占 1 格

- 一级评论：白色底卡片 + 头像 + 昵称 + 时间 + 内容 + 点赞/回复

- 最多嵌套 2 层，更深回复折叠"查看更多"
- 点击"回复"展开输入框，@ 被回复者

### 6.6 底部输入栏
- flex-shrink:0 固定在视口底部，不随评论滚动
- 用户头像(26px) + 输入框占位 + 点赞按钮
- 点击输入框 → 聚焦评论输入模式
