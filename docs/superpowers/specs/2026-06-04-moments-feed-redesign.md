# 动态 Feed 流卡片设计升级

**日期**：2026-06-04
**范围**：仅改 MomentsFeed.tsx 中的 FeedCard 和 FollowTimeline 两个组件

## 目标

将推荐 Tab 的 FeedCard 从小红书传统的全宽白色卡片改为双列瀑布流 + 文字渲染图片卡片。
将关注 Tab 的 FollowTimeline 从彩色时间线改为微信朋友圈风格。

## 不改动的部分

- 顶部导航栏（标题、Tab 切换、搜索/通知图标）
- HotTopicBanner 热门话题轮播
- MosaicPool 推荐好友横滚 + 话题滚动
- 浮动发布按钮（Plus 圆形按钮）
- ImageViewer 图片查看器
- 无限制分页加载逻辑（向上滚动加载更多）
- Socket.IO 实时更新（moment:new, moment:notification 等）
- 所有其他页面组件

## 推荐 Tab：FeedCard 改为双列瀑布流

### 布局

- 使用 CSS Grid `grid-template-columns: 1fr 1fr`，列间距 8px
- 卡片不再全宽，两列各自承载一张卡片
- 实现真正的瀑布流效果（左右列高度分别计算，新卡片插入较短的一列）

### 卡片样式

**全部卡片：**
- 无边框（`border: none`）
- 无阴影（`box-shadow: none`）
- 圆角 10px
- overflow: hidden

**图片动态卡片：**
- 图片上方展示，圆角裁切
- 图片下方 8-10px padding 区域：文字摘要、头像、昵称、等级徽章、时间
- 互动数据（点赞数、评论数、分享）在底部横排

**纯文字动态卡片（文字渲染为图片卡片）：**
- 无真实图片时，文字动态渲染为纯背景色卡片
- 文字**居中排版**，有标题/副文字的字号对比
- 装饰元素仅使用几何线条（细横线、圆点、圆环），不用 emoji
- 三种视觉风格随机混合，从以下调色板随机选取：

| 风格 | 背景色 | 文字主色 | 装饰元素 |
|------|--------|----------|----------|
| 暖米杂志 | `linear-gradient(170deg, #F5F0EB, #EDE4D8)` | `#3D2B1B` | 顶部细横线 |
| 淡紫留白 | `linear-gradient(170deg, #F3EFFF, #EDE7F6)` | `#4A3D6B` | 角落圆点 |
| 暗棕几何 | `linear-gradient(170deg, #2D1B1B, #3D2B2B)` | `rgba(255,255,255,0.9)` | 大圆环 |
| 暖橙渐变 | `linear-gradient(170deg, #FFF0E5, #FFE0D0)` | `#8B4A3A` | 双圆环 |
| 青绿纯色 | `#4ECDC4` 或 `#3DB8B0` | `rgba(255,255,255,0.95)` | 圆点组 + 圆环 |
| 深绿暗色 | `linear-gradient(170deg, #1B3A2D, #2D5A3D)` | `rgba(255,255,255,0.9)` | 顶部横线 + 大圆环 |

### 保留的卡片元素

- 头像（14px 圆形）
- 昵称
- 等级徽章（LV.x 小标签）
- 时间（相对时间显示）
- 话题标签（彩色小标签）
- 点赞数 + 评论数 + 分享按钮（底部横排）
- 关注/已关注按钮（他人动态）或更多操作菜单（自己的动态）
- 图片查看器（点击图片触发）
- 点赞动画粒子效果
- @提及内容渲染

### 文字卡片内部排版

```
┌──────────────────┐
│   [装饰线/圆环]    │
│                  │
│   标题（大字）     │
│   文字居中        │
│                  │
│   [分隔线/圆点]   │
│                  │

│   补充描述        │

```

## 关注 Tab：FollowTimeline 改为微信朋友圈风格

### 布局

- 背景色改为 `#F5F5F5`（浅灰，区分于推荐页暖白）
- 单列纵向排列，每个条目：左头像 + 右内容区
- 头像：38px，方形圆角 4px（微信朋友圈风格，非圆形）
- 无卡片容器包裹，内容直接排版

### 日期分组

- 居中显示日期标签："今天"、"昨天"、"X月X日"
- 灰色文字 `#B0B0B0`，字号 11px
- 替代当前的彩色圆点标记方式

### 保留的卡片元素

- 头像、昵称（蓝色 `#576B95` 微信风格链接色）
- 文本内容（14px，黑色 `#333`）
- 图片网格（3列自适应）
- 话题标签
- 位置信息
- 时间（在底部左侧）
- 评论入口（在底部右侧）
- 语音条（渐变色条样式）
- 关注/取关按钮（不在自己的动态上显示）

### 数据加载

- 保持现有的 IntersectionObserver 无限分页加载
- 保持现有的加载状态（spinner）
- 保持现有的空状态提示

## 实现文件

| 文件 | 修改内容 |
|------|----------|
| `src/pages/Moments/MomentsFeed.tsx` | FeedCard 组件重写为瀑布流布局；MosaicPool/HotTopicBanner/导航栏不动 |
| `src/components/FollowTimeline.tsx` | 重写为微信朋友圈风格单列时间线 |

## 技术要点

- 瀑布流：维护左右两列高度，将新卡片插入较矮的一列，使用 CSS Grid 渲染
- 文字卡片风格：根据动态 ID 取模或随机决定风格类型，纯 CSS 渐变 + inline style 实现，不引入额外图片资源
- 性能：瀑布流内的长列表继续使用触底加载（IntersectionObserver），不引入虚拟列表
- 响应式：移动端保持双列（每列约 50% 宽度），桌面端无需特殊适配
