# 消息列表顶部栏重设计

**日期**: 2026-06-02

## 设计来源

- B: 过滤芯片（全部/未读/群聊/@我）
- A: + 按钮展开动态操作栏（创建群聊/添加好友/我的群聊）
- C: 浮动 pill 搜索栏（白色阴影，无边框）

## 布局结构（从上到下）

### 默认态
1. 标题行："消息" + 未读数 + [+] 按钮
2. 搜索栏：白色浮动 pill（shadow-sm, rounded-2xl）
3. 过滤芯片：全部 · 未读 · 群聊 · @我
4. 对话列表（置顶 item 暖色背景区分，无 pin 图标）

### 展开态（点击 +）
- + 旋转 45° 变 x
- 搜索栏上方滑出 3 格操作栏

### 过滤交互
- 点击芯片切换 active 态（深色文字底）
- 全部：显示所有
- 未读：只显示未读>0
- 群聊：只显示群聊
- @我：只显示有 @提及的群聊
