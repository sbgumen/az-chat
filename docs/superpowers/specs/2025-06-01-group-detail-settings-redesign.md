# 群详情页 & 群设置页 UI 重设计

## 概述

将群聊相关的两个页面进行 UI 重设计和路由重构：

1. **群详情页** (`GroupDetailPage`) — 改为真正的路由页面，支持多入口访问
2. **群设置页** (`GroupInfoPage`) — 重设计 UI，群信息头部点击改为路由跳转

设计风格：**Warm Editorial**（暖调杂志排版），无卡片边框，强文字层级，Lucide 图标。

---

## 路由变更

### 当前状态
- `GroupDetailPage` 在 `App.tsx` 已有路由 `/messages/group/:groupId/detail`
- 但 `GroupInfoPage` 使用内联方式渲染：`<GroupDetailPage groupId={gid} onClose={...} zIndex={320} />`

### 目标状态
- `GroupInfoPage` 点击群信息头部 → `navigate('/messages/group/:groupId/detail')`
- `GroupDetailPage` 移除 `onClose` / `zIndex` props，通过 `useParams` 获取 groupId，返回按钮用 `useNavigate(-1)`
- 其他入口（添加/搜索页、分享链接）也可跳转到 `/messages/group/:groupId/detail`

### 关键行为
- **群信息头部** — `onClick` → `navigate('/messages/group/:groupId/detail')`
- **Toggle 开关** — 调用 `POST /api/messages/settings/:targetId` 更新置顶/免打扰状态
- **搜索聊天记录** — 导航到现有 `SearchChatHistory` 组件
- **群成员** — 点击头像进入成员管理/用户资料；点击「查看全部」→ 成员列表页
- **群公告** — 导航到公告列表页
- **群管理** — 导航到 `GroupManagePage`（现有路由保持不变）
- **退出群聊** — 弹出确认 sheet

### 数据获取
- `getGroupDetail(groupId)` — 群信息（名称、头像、成员列表、角色、加群方式）
- `getGroupNotices(groupId)` — 最新公告预览
- `getConversationSettings(groupId, 'group')` — 置顶/免打扰状态

```
│                                           │
├─ 底部按钮 ────────────────────────────────┤
│         [ 加入群聊 ]                      │
│     (按身份/状态动态切换)                 │
└───────────────────────────────────────────┘
```

### 底部按钮逻辑（核心状态机）

| 用户身份 | 群状态 | 按钮文案 | 行为 |
|---------|--------|---------|------|
| 非成员 | 直接加入 | `加入群聊` | POST 加入 |
| 非成员 | 需审批 | `申请加入` | POST 申请 |
| 非成员 | 已申请待审 | `等待审核中` | 不可点击，灰色 |
| 已是成员 | 正常 | `发消息` | navigate 到群聊窗口 |
| — | 群已封禁 | `该群已被封禁` | 不可点击，红色 |
| — | 用户被封禁 | 不显示按钮 | — |
| 群主 | 正常 | `管理群聊` | navigate 到群管理 |

### 数据获取
- `getGroupDetail(groupId)` — 所有群信息
- 需要检查当前用户是否是成员（在 members 数组中查找）
- 需要检查是否有待审申请（`GET /api/groups/my-requests`）

### 入口来源
1. 群设置页 — 点击群信息头部
2. 添加/搜索页 — 搜索群 ID 或名称后点击
3. 群聊窗口 — Header 菜单按钮
4. 外部分享链接
