# 腾讯云短信服务接入文档

## 一、前置准备

| 项目 | 说明 |
|------|------|
| 腾讯云账号 | 已实名认证（企业认证优先） |
| 预算 | 国内短信约 **0.05元/条**，首次有 **100条免费额度** |

---

## 二、配置流程（共 4 步）

### 第 1 步：创建短信应用

1. 登录 [短信控制台](https://console.cloud.tencent.com/smsv2)
2. 左侧导航 → **应用管理** → **应用列表**
3. 点击 **创建应用**，输入应用名称（如 `AZ-Chat`）和简介
4. 创建后，在列表中找到该应用，点击获取 **SDK AppID**（如 `1400006666`）

> ⚠️ 该应用对应的 **App Key** 是校验请求合法性的密码，**需要高度保密**。

---

### 第 2 步：申请短信签名

1. 在短信控制台左侧 → **国内短信** → **签名管理**
2. 点击 **创建签名**
3. 填写参数：

| 参数 | 推荐值 |
|------|--------|
| 签名用途 | 自用 |
| 签名类型 | 公司（或 APP、商标等） |
| 签名内容 | 例如 `AZ聊天`（不加【】） |
| 证明文件 | 上传营业执照等资质文件 |

4. 提交审核。预计 **2小时** 内完成平台审核。
5. ⚠️ 审核通过后还需运营商实名报备，**通常 7-10 个工作日**。

> **注意**：个人认证用户无法进行运营商实名报备，建议升级为企业认证。

---

### 第 3 步：创建短信模板

1. 在短信控制台左侧 → **国内短信** → **模板管理**
2. 点击 **创建模板**
3. 填写参数：

| 参数 | 说明 | 示例 |
|------|------|------|
| 模板名称 | 自定义 | 验证码通知 |
| 模板类型 | 验证码 / 通知 / 营销 | 验证码 |
| 模板内容 | 正文，变量用 `{1}` `{2}` 占位 | `您的验证码为：{1}，{2}分钟内有效，请勿泄露。` |

4. 提交审核（通常 2 小时内完成）

---

### 第 4 步：获取 API 密钥

1. 登录 [访问管理控制台](https://console.cloud.tencent.com/cam/overview)
2. 左侧 → **用户** → **用户列表**
3. 选择一个用户（或新建子用户），进入详情
4. 点击 **API 密钥** 标签
5. 点击 **新建密钥**，生成一对 **SecretId** 和 **SecretKey**

> ⚠️ SecretKey 只显示一次，请立即妥善保存。

---

## 三、调用所需参数汇总

| 参数 | 来源 | 用途 |
|------|------|------|
| `SecretId` | 第 4 步 | API 鉴权（身份标识） |
| `SecretKey` | 第 4 步 | API 鉴权（签名密钥） |
| `SmsSdkAppId` | 第 1 步 | 标识短信应用 |
| `SignName` | 第 2 步 | 短信签名内容，如 `AZ聊天` |
| `TemplateId` | 第 3 步 | 短信模板 ID，如 `1234567` |
| `PhoneNumber` | 业务侧 | 接收方手机号，如 `+8613800138000` |
| `TemplateParam` | 业务侧 | 模板变量值，如 `["123456","5"]` |

---

## 四、调用方式

### 方式一：使用腾讯云 SDK（推荐）

```bash
npm install tencentcloud-sdk-nodejs-sms
```

```ts
import * as tencentcloud from 'tencentcloud-sdk-nodejs-sms'

const client = new tencentcloud.sms.v20210111.Client({
  credential: {
    secretId: '你的 SecretId',        // 替换
    secretKey: '你的 SecretKey',      // 替换
  },
  region: 'ap-guangzhou',
})

client.SendSms({
  PhoneNumberSet: ['+8613800138000'],  // 替换
  SmsSdkAppId: '1400006666',           // 替换
  SignName: 'AZ聊天',                   // 替换
  TemplateId: '1234567',               // 替换
  TemplateParamSet: ['123456', '5'],   // 替换
}).then(
  res => console.log('发送成功:', res),
  err => console.error('发送失败:', err)
)
```

### 方式二：直接调用 API（Python 示例）

```python
import json
import hashlib
import hmac
import base64
import time
import random
import requests

def send_sms(secret_id, secret_key, sdk_app_id, sign_name,
             template_id, phone_numbers, template_params):
    service = 'sms'
    host = 'sms.tencentcloudapi.com'
    version = '2021-01-11'
    action = 'SendSms'
    region = 'ap-guangzhou'
    algorithm = 'TC3-HMAC-SHA256'
    timestamp = int(time.time())

    # 1. 构建请求体
    payload = json.dumps({
        'PhoneNumberSet': phone_numbers,
        'SmsSdkAppId': sdk_app_id,
        'SignName': sign_name,
        'TemplateId': template_id,
        'TemplateParamSet': template_params,
    })

    # 2. 计算签名（略，建议直接用 SDK）
    # 完整签名流程参考：
    # https://cloud.tencent.com/document/product/382/55981

    headers = {
        'Content-Type': 'application/json',
        'X-TC-Action': action,
        'X-TC-Region': region,
        'X-TC-Timestamp': str(timestamp),
        'X-TC-Version': version,
    }
    # … 省略完整签名计算，实际请用 SDK

# 调用示例
send_sms(
    secret_id='你的 SecretId',
    secret_key='你的 SecretKey',
    sdk_app_id='1400006666',
    sign_name='AZ聊天',
    template_id='1234567',
    phone_numbers=['+8613800138000'],
    template_params=['123456', '5'],
)
```

> 💡 **建议直接用腾讯云 SDK**，签名计算已封装好，省去繁琐步骤。

## 六、注意事项

1. **签名和模板必须都审核通过**才能发送短信，缺一不可
2. 单次请求最多 **200 个手机号**
3. 发送频率限制：同一手机号 **30 秒内不超过 1 条**
4. 模板参数个数必须与模板定义的变量个数一致
